# Обучающий проект для изучения DRF в Python

## Описание:

Проект представляет из себя backend сервис для образовательной платформы.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Rayour/DjangoRest.git
```
2. Запуск проекта:
Для работы с проектом необходимо установить redis и docker.
Далее выполните команду
```
docker-compose up --build
```
Проверка работоспособности сервисов:
Выполните команду
```
docker-compose ps
```
В терминале будет выведена таблица сервисов, если в колонке `STATUS` для всех сервисов указано `UP`, значит все запущены.

Для разворота проекта на виртуальной машине выполните следующие шаги:
1. Подключитесь к виртуальной машине по инструкции от поставщика услуги
2. Обновите список пакетов `sudo apt update`
3. Обновите пакеты до последних версий `sudo apt upgrade`
4. Установите docker по инструкции с официального сайта https://docs.docker.com/engine/install/ubuntu/#install-using-the-repository.
5. Настройте файервол:
   1. Проверьте статус файервола `sudo ufw status`
   2. Если файервол отключен - активируйте `sudo ufw enable`
   3. Откройте порты для http, https и ssh:
   ```
    sudo ufw allow 80/tcp
    sudo ufw allow 443/tcp
    sudo ufw allow 22/tcp
    ```
   4. Проверьте статус файервола, убедитесь, что порты открыты `sudo ufw status`
6. Создайте в репозитории следующие secrets:
   * DEPLOY_DIR - директория для деплоя приложения
   * DOCKER_HUB_ACCESS_TOKEN - docker hub access token 
   * DOCKER_HUB_USERNAME - docker hub username
   * SERVER_IP - публичный IP вашей виртуальной машины
   * SSH_KEY - ключ для подключения по ssh
   * SSH_USER - пользователь для подключения по ssh к вашей виртуальной машине

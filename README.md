# Обучающий проект для изучения DRF в Python

## Описание:

Проект представляет из себя backend сервис для образовательной платформы.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/Rayour/DjangoRest.git
```
2. Запуск проекта:
Для работы с проектом необходимо установить redis и docker.
Далее выполните команду
```
docker-compose up --build
```
Проверка работоспособности сервисов:
Выполните команду
```
docker-compose ps
```
В терминале будет выведена таблица сервисов, если в колонке `STATUS` для всех сервисов указано `UP`, значит все запущены.
